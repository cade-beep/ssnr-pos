📋 간이 POS 시스템 프로젝트 실습 기록 포트폴리오

프로젝트명: 서산나래 베이커리 & 카페 특화 간이 POS 시스템

개발 기간: 2026. 07. 23 ~ 2026. 09. 01

📌 1. 프로젝트 개요 (Executive Summary)

실제 베이커리 & 카페 매장에서 빠른 터치 주문, 정확한 수량 누적, 세분화된 품목/전체 할인, 감열 영수증 출력, 오프라인 결제 동기화, 권한 기반 정산 관리가 가능하도록 설계된 고밀도 전문 SaaS형 POS 웹/데스크톱 애플리케이션입니다.

💡 3. 핵심 문제 해결 (Troubleshooting)

문제 1: 빠른 연속 클릭 시 수량 누락

해결: React 함수형 상태 업데이트(setCart(prev => ...)) 패턴으로 전면 교체하여 1초에 4회 이상 연타해도 100% 무손실 수량 누적 달성.

문제 2: 할인 적용 상품의 부분 환불 금액 오차

해결: 주문 시점에 각 품목별 실결제액(line_total)을 분할 저장하고, 부분 환불 RPC(refund_order_items)에서 line_total 비율로 정확한 실결제액만 환불되도록 보정.

문제 3: 매장 인터넷 단절 시 결제 차단 위험

해결: IndexedDB 기반 오프라인 큐(offlineQueue.ts)를 구축하여 오프라인 시 로컬 저장 후 온라인 복구 시 자동 재전송하도록 안전장치 구현.

문제 4: 상품 수가 적은 카테고리에서 카드가 세로로 늘어나는 현상

해결: .product-grid에 align-content: start; 및 카드에 height: auto;를 적용하여 상품 개수와 상관없이 일정한 규격 유지.
